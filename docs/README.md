# Документация

Эта папка содержит короткие опорные документы для навигации по проекту.

| Файл | Что внутри |
|---|---|
| `RUNNING.md` | подготовка окружения и типовые команды запуска |
| `DATA_SCHEMA.md` | основные parquet/csv-файлы и смысл ключевых колонок |
| `MODELS.md` | prefilter, BERT topic model, direction model и inference |
| `TRAINING_PROCESS.md` | история постановки задачи и обучения моделей |

Более подробные исторические заметки по архиву `pipeline/` лежат в `pipeline/docs/`.
