# telegram_signal_searcher

Проект для анализа постов Telegram и поиска экономических сигналов, связанных с сигналами из пресс-релизов ЦБ.

## Цель проекта

Построить пайплайн, который:
1. извлекает посты из Telegram JSON;
2. сохраняет их в удобном формате;
3. позволяет находить посты, близкие по смыслу к экономическим сигналам.

## Структура проекта

- `data/raw/` — сырые данные
- `data/clean/` — очищенные данные
- `data/processed/` — данные для анализа и ML
- `data/predictions/` — результаты
- `src/` — основной код
- `notebooks/` — исследовательские ноутбуки
- `models/` — модели
- `configs/` — конфиги
