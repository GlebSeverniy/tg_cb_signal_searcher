# Документация проекта

В этой папке собраны исторические markdown-описания по архиву `pipeline/`.
Короткая актуальная навигация по всему проекту вынесена в корневые документы:

| Файл | Содержание |
|---|---|
| `../../README.md` | общий обзор проекта и быстрый старт |
| `../../docs/RUNNING.md` | команды запуска |
| `../../docs/DATA_SCHEMA.md` | схема данных и ключевые колонки |
| `../../docs/MODELS.md` | модели, thresholds и inference |
| `../../docs/TRAINING_PROCESS.md` | история обучения |

Локальные документы:

| Файл | Содержание |
|---|---|
| `bert_training_history.md` | как обучался BERT, какие были постановки, версии, метрики и результаты |
| `tgstat_idea_and_attempts.md` | зачем пробовали TGStat, как собирались просмотры/подписчики и почему это оказалось сложным |
| `telegram_posts_parser.md` | как устроен сбор и парсинг Telegram-постов, какие поля сохраняются и как они идут дальше в BERT |

Документы опираются на файлы текущего архива `bert_corpus_v3_revised_t1t4` и на код соседнего проекта `../SignalSearcher/telegram_signal_searcher`, где лежат первичные Telegram/TGStat-скрипты.
