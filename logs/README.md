# Логи

Здесь лежат журналы локальных запусков Telegram/TGStat-скриптов.

## Основные файлы

| Файл | Назначение |
|---|---|
| `download_log.csv` | результат скачивания каналов через Telethon |
| `extract_log.csv` | результат извлечения сообщений из JSON |
| `download_log_merged.csv` | объединённый/производный лог |
| `merge_logs.py` | вспомогательный скрипт для объединения логов |

## Входы

Логи создаются автоматически при запуске `src/download_tg_channels.py` и `src/extract_posts.py`.

## Выходы

CSV с колонками статуса, каналом, числом сообщений, путём output-файла и ошибкой, если она была.

## Примечания

Логи помогают восстановить, какие каналы скачались успешно, а какие нужно перезапустить.
