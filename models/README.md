# Модели

Корневая папка `models/` сейчас пуста и зарезервирована под будущие локальные модели.

## Где лежат текущие модели

| Путь | Назначение |
|---|---|
| `pipeline/model_topic/` | сохранённая ruBERT topic model |
| `pipeline/model_direction/` | сохранённая ruBERT direction model |
| `pipeline/classifiers/` | prefilter-классификаторы |

## Примечания

Важно: большие веса моделей обычно не стоит коммитить. В текущей рабочей папке финальные веса лежат в `pipeline/`.
