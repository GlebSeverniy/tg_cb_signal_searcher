# Скрипты `scripts`

Папка сейчас пуста. Рабочие скрипты проекта находятся в `src/` и `pipeline/classifiers/scripts/`.

## Как использовать

Используйте:

```text
src/
pipeline/classifiers/scripts/
```

## Примечания

Папку можно оставить как место для будущих orchestration-скриптов, но сейчас она не является entry point.
